# Güvenlik ve mahremiyet

TeyitScope görselleri varsayılan olarak kalıcı depolamaz. Üretim API'sinde dosya boyutu, MIME doğrulaması, rate limit, geçici dosya temizliği ve erişim günlükleri için kendi politikanızı uygulayın. Hassas görüntüleri rıza olmadan yüklemeyin. Güvenlik sorunlarını public issue yerine sorumlu bildirim kanalıyla proje sahibine iletin.
